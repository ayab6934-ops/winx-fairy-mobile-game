# Winx Fairy Vanguard

This repository is a Godot 4 prototype inspired by a dreamier, mobile-friendly Winx fantasy action adventure. It captures the Y2K pastel color direction, modular character assembly, magical combat, room-based progression, and simple world systems described in the production blueprint.

## Included prototype features

- Character selection with Water, Fire, Nature, and Air element archetypes
- Gender-based styling and player state persistence
- Inventory, dust currency, potion crafting, and save system
- Fairy flight movement with touch-friendly controls and keyboard fallback
- Magical boomerang-style projectile casting
- Enemy AI and summon-style beast behavior
- Stylized 3D world with sky gradient and sunset lighting
- Mobile-friendly UI structure ready for later screen polish

## Project structure

- `project.godot` — Godot project configuration
- `scripts/autoloads/` — global singletons for character, inventory, and save state
- `scripts/character/` — playable fairy logic, enemy AI, and summon behavior
- `scripts/gameplay/` — world generation and scene setup
- `scripts/ui/` — character selection and UI flow
- `scenes/` — entry scenes

## How to run

1. Open the folder in Godot 4.
2. Import the project.
3. Press Play.
4. Choose an element and gender, then enter Alfea.

## Notes

This is a prototype, not a full production game. The goal is to give you a strong playable foundation with the visual language and systems from your concept document, while staying lightweight enough for iteration and expansion.
